# Dependencies for this project are installed via apt, not pip, and the venv
# is created with --system-site-packages to see them:
#
#   sudo apt-get install -y python3-numpy python3-scipy python3-pandas \
#       python3-sklearn python3-matplotlib python3-joblib python3-requests \
#       python3-tqdm python3-venv
#   python3 -m venv --system-site-packages venv
#
# Why apt instead of pip: PyPI downloads of the large compiled wheels
# (scipy/scikit-learn/matplotlib, tens of MB each) repeatedly stalled under
# throttled network conditions in this environment (established after
# multiple stalled/killed pip installs), while apt's Ubuntu mirror was fast
# and reliable for the exact same packages every time it was used in this
# project. If you're on a machine with normal PyPI throughput, plain
# `pip install -r requirements.txt` with the pinned versions below will also
# work -- both are listed for reproducibility.
#
# apt-installed versions actually used in this project:
#   numpy==1.26.4  scipy==1.11.4  pandas==2.1.4  scikit-learn==1.4.1.post1
#   matplotlib==3.6.3  joblib==1.3.2  requests==2.31.0  tqdm==4.66.2
#
# pip-equivalent pins, if you install via pip instead:
requests==2.32.3
pandas==2.2.3
tqdm==4.66.5
numpy==2.1.3
scipy==1.14.1
